# مساحتي — Masahati

تطبيق ويب عربي (RTL) للملاحظات والأفكار والمهام، يعمل على المتصفح ويمكن تثبيته كتطبيق على الأجهزة المتوافقة.

## النشر على GitHub Pages
1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
4. انتظر انتهاء النشر، ثم افتح: https://bilelghanem.github.io/Misahati.app/

## ملاحظات
- تُحفظ البيانات محليًا في المتصفح والجهاز الحالي عبر Local Storage.
- استخدم زر النسخة الاحتياطية داخل التطبيق لتصدير بياناتك بملف JSON واحتفظ به في مكان آمن.
- حذف بيانات المتصفح أو استخدام جهاز/متصفح مختلف قد يجعل بياناتك المحلية غير متاحة؛ استورد نسخة احتياطية عند الحاجة إذا كانت ميزة الاستيراد متوفرة في إصدار التطبيق.
- المزامنة السحابية غير مفعلة افتراضيًا.
